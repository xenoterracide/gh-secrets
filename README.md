# gh-secrets

A small CLI that pushes GitHub Actions secrets to many repositories selected by owner/org + repo topic.

This repo is intended to wrap `gh` (GitHub CLI) + `gpg` in a repeatable, testable way.

## Status

Scaffolded project layout and baseline repo conventions. Implementation pending.
